# IPL All-Time Auction Game ??

A real-time multiplayer web auction game featuring 59 iconic all-time IPL legends.

## How to Start

### Option 1 — One Command (Full Stack)
```
npm start
```
Opens at: **http://localhost:4000**

### Option 2 — Development Mode (Hot Reload)
Terminal 1:  `npm run dev:server`
Terminal 2:  `npm run dev:client`
Client at: http://localhost:5173
